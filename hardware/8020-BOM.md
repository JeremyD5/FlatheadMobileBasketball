# 80/20 Bill of Materials — Lane Divider Panels

Metal parts only. Upper (see-through) half of the lane dividers. Everything below the ball-return line is wood and is not in this document.

**All prices pulled from [8020.net](https://8020.net/) on September 10, 2026.** Verify before ordering — 80/20 changes pricing and stock regularly.

---

## Design basis

The whole BOM is driven by one number: **80/20's wire mesh stock sheet is 57.75" × 92.625".**

Order that exact size and you skip a $15.74 cut charge per sheet. It is also almost exactly the 93" depth of a commercial arcade basketball station, which is not a coincidence — 80/20 sizes this mesh for machine guarding, which is the same problem.

**So each divider panel is designed around one full stock mesh sheet.**

| Dimension | Value |
|---|---|
| Mesh sheet (1 per panel) | 57.75" H × 92.625" W |
| Frame outer size | ~60.25" H × ~95.13" W |
| Panel count, full build | 5 (4 lanes, both ends closed) |
| Panel count, minimum | 3 (interior dividers only; trailer walls close the ends) |
| Weight per panel | ~70 lb |

Frame members per panel: 2 horizontal rails at 95.13", 2 end verticals at 57.25", 1 mid stiffener at 57.25".

### Hidden joints instead of external brackets

80/20 will machine the extrusion so joints disappear. Priced per operation on the [1515 page](https://8020.net/1515.html):

| Operation | Price |
|---|---|
| Anchor fastener counterbore | $4.01 |
| Butt fastener | $4.01 |
| End tap, 5/16-18 | $3.00 |
| Access hole, .295" | $3.00 |
| Mitercut, 0°–75° | $5.31 |
| Central connector | $6.46 |

An end-tap + access-hole butt joint is ~$6 plus a screw, versus ~$11–16 for a bracketed corner. Cleaner and cheaper, but zero adjustability once cut, and it adds lead time. Not the right call for a v1 you expect to modify.

## 🔑 The one thing to price before ordering any of this

<img src="https://8020.net/media/catalog/product/cache/aa8806fc690eba794f5aa097363986c3/2/4/245882_8020_main_1.jpg" width="120">

**[Framed Machine Guard Panel](https://8020.net/framed-machine-guard-panel.html) — "as low as $120.15"**

These are **pre-built framed mesh panels**. Frame and mesh, assembled, done. The 2486 mesh spec explicitly notes it matches these: part numbers **PN241082, PN242282, PN243482, PN244682, PN245882**.

If one of those sizes is close to 57.75" × 92.625", buying five framed panels could come in dramatically under the $3,648 of building frames from raw extrusion. Even at $350 each that's $1,750 versus $3,648.

**Call 80/20 and get the sizes and prices for those five part numbers before doing anything else in this document.**

## Reality check on cost

| Approach | 5 panels | Notes |
|---|---|---|
| Chain link fence framework | $600–1,200 | Cheapest. Looks like a fence, which is what the commercial machines look like anyway |
| Kee Klamp + welded wire | $1,500–2,500 | Adjustable, galvanized, hex key only |
| **80/20 (this document)** | **$3,950–4,250** | Lightest, most precise, mesh drops into the slot |
| Pre-framed 80/20 guard panels | **TBD — get quote** | Possibly the sweet spot |

**80/20 is roughly 3–4× the fence-pipe approach.** What you're buying for that premium:

- **~250 lb less weight** than steel pipe across five panels, all of it high in the trailer where it affects towing most
- Mesh captures directly in the T-slot, no separate retainer system or welding
- Fully reconfigurable — loosen a set screw and move a rail when v1 turns out wrong
- It looks intentional rather than improvised, which matters if you're charging $550 a booking

Whether that's worth $2,500 depends on how much the finished look matters to the business. For a v1 prototype it almost certainly isn't. For the production build it might be.
