# Kee Klamp BOM — Angled Lane Dividers

Metal only, upper see-through zone. Angled top rail matching the commercial arcade machine profile.

**Prices from [Simplified Building](https://www.simplifiedbuilding.com/pipe-fittings/kee-klamp), September 10, 2026.**

---

## ⚠️ Two corrections to earlier notes in this repo

**1. Cost.** An earlier note estimated Kee Klamp at $1,500–2,500 for five panels. That was wrong. Kee's fixed fittings are $22–70, but the **adjustable-angle** fittings required to land a sloped rail on a vertical post run **$56–$142 each**, three per panel, fifteen across the build.

**2. Mesh capture.** An earlier note in this file claimed Kee has no way to capture a rigid mesh panel. **That was also wrong.** Kee Safety makes purpose-built mesh clips:

| Type | Fitting | Size 7 price |
|---|---|---|
| [81-7](https://www.simplifiedbuilding.com/pipe-fittings/kee-klamp/81-7-single-sided-clip-1-1-4) | **Single Sided Clip** — attaches wire mesh infill to one side of the pipe | **$10.40** |
| [82](https://www.simplifiedbuilding.com/pipe-fittings/kee-klamp/82-double-sided-clip) | **Double Sided Clip** — mesh on both sides of the same pipe | price by size |

Both handle infill **up to 3/8" thick**. The 80/20 [2486 mesh panel](https://8020.net/2486.html) is 0.256" thick, so the exact same rigid mesh works in either system. Type 81 also works without the safety attachment for plexiglass or printed banner panels, which opens up a graphics option for the outer end panels.

Available in sizes 6 through 9: [81-6 (1")](https://www.simplifiedbuilding.com/pipe-fittings/kee-klamp/81-6-single-sided-clip-1), [81-7 (1-1/4")](https://www.simplifiedbuilding.com/pipe-fittings/kee-klamp/81-7-single-sided-clip-1-1-4), [81-8 (1-1/2")](https://www.simplifiedbuilding.com/pipe-fittings/kee-klamp/81-8-single-sided-clip-1-1-2), [81-9 (2")](https://www.simplifiedbuilding.com/pipe-fittings/kee-klamp/81-9-single-sided-clip-2).

Both totals below are corrected.

## Panel geometry

Shared dividers: 4 lanes need 5 panels (3 interior + 2 ends), or 3 if the trailer front and rear walls close the ends.

| Member | Length |
|---|---|
| Back post (backboard end) | 78" |
| Front post (player end) | 54" |
| Mid post (stiffener) | 66" |
| Bottom rail (at ball-return height, ~30" above floor) | 93" |
| Angled top rail (√(93² + 24²)) | 96" |
| **Pipe per panel** | **387" ≈ 32.25 ft** |

Mesh trapezoid: 93" long, 48" tall at the backboard end tapering to 24" at the player end. **23.25 sq ft**, perimeter **261"**.

The 48" tall edge fits inside 80/20's 57.75" stock sheet height, so no sheet-splitting required.

Pipe size: **Kee size 7** (1.660" OD, 1-1/4" nominal). Standard structural railing size.

**Kee is the most expensive by a wide margin.** But it's also the only one of the three with a published structural load rating, and kids hanging on these panels is a real load case. It's also the only one with a purpose-built anti-tamper solution, which matters when the unit is left unattended at a party — the Hoop network's own FAQ says operators drop the trailer and leave.

Standards: ASTM A47-77-32510, BS EN ISO 1461. Galvanized cast steel with Kee Koat set screws.

## Recommendation

**Fence framework for v1.** Validate the angle, lane width, and rim height at $1,490 before spending $5,525 on hardware that locks in dimensions you haven't tested with actual kids.

For the production build the choice is genuinely between 80/20 and Kee, and it comes down to what you're buying:

- **80/20** is $1,575 cheaper, 210 lb lighter, and the T-slot captures mesh for free.
- **Kee** is engineered to a published load number, galvanized rather than anodized (better in Montana winters and road salt), and has the 97ATD anti-tamper rivet that no other system offers.

If the trailer gets left unattended at events, the tamper argument is worth real money.
